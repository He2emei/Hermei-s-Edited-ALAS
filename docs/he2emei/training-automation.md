## 适用范围与配置

训练换船只支持国服 CN、1280×720 画面。`module/os/training_ui.py` 会检查服务器和分辨率，不满足时转人工接管。

相关配置位于 `OpsiTraining`：

```json
{
  "OpsiTraining": {
    "Enable": false,
    "CheckIntervalMinutes": 60,
    "ProtectedMainShip": "英仙座",
    "ProtectedVanguardShip": "伊吹",
    "LastCheck": 0
  }
}
```

- `Enable` 默认关闭；只有显式开启后才允许训练维护流程。
- `CheckIntervalMinutes` 是两次成功检查的最小间隔，默认60分钟；只在侵蚀1战略搜索之间检查，受其他任务切换和搜索结束时间影响，不保证整点执行。
- `LastCheck` 是运行时检查时间戳，用于间隔控制，不应当被当作训练进度。
- `ProtectedMainShip` / `ProtectedVanguardShip` 是该账号第四舰队1/4号位的预期舰名。默认英仙座/伊吹，必须与实际舰及资料库阵位精确匹配；它们只用于保护校验，不会自动替换这两个位置。2026-09-15用户确认ALAS2使用英仙座/普利茅斯。
- 2026-09-15修复`LastCheck`隐藏输入字段重载归零导致反复检查的问题；该字段使用只读展示，保留已写入的整数时间戳。
- 任务入口挂在 `OpsiHazard1Leveling`，触发时机仍受该任务的 hazard-one 练级流程和主调度条件约束。

战术书优化是独立开关 `Tactical.OptimizeBooks`（生成配置名为 `Tactical_OptimizeBooks`），默认关闭；它不会隐式开启 `AddNewStudent`。新生配置仍由 `AddNewStudent.Enable`、`Favorite`、`MinLevel` 独立控制。

## 换船规则

训练使用第四舰队。1/4号位保留该账号配置的带练舰（默认英仙座/伊吹）；自动换船只规划 2、3、5、6 号位。换船前后会重新读取舰队身份，保留舰变化或舰队状态不确定时停止。

普通舰满足满破后才可训练；彩舰可绕过普通舰的满破限制，但仍必须有可识别的舰船、等级和上限信息。125 级完成舰不再训练。达到等级上限时，必须能读到已存经验；普通舰至少110级、彩舰至少115级，且已存经验达到 3,000,000 时才按完成处理。未知等级上限、未知已存经验、身份不稳定或 OCR 不合法都会放弃候选，避免误换船。

觉醒策略识别普通舰和彩舰的上限边界；配置说明中的目标上限是普通舰 110 级、彩舰 120 级，且不消耗心智单元 II。觉醒调用最多重试有限次数，但材料提交和觉醒的真实消耗流程尚未有当前场景验收，不能据此判断实机成功。

## 候选扫描与翻页维护

候选扫描按当前屏幕实际返回的船卡 Button 顺序处理，不使用翻页后仍可能失真的固定网格坐标。每次 `DOCK_SCROLL` 后等待约 0.6 秒、重新截图并重新扫描当前可见卡片；最多翻页 40 次，遇到底部或重复页面停止。候选数量有界，重复页面不会造成循环。

船卡等级 OCR 区域相对当前 Button 的区域 `(77, 5, 138, 27)` 解释。学院当前共4个栏位，其中2个未解锁；付费锁位不作为空闲栏位点击，不购买栏位。

## 同色战术书规划

当 `Tactical.OptimizeBooks` 开启时，只使用与技能颜色匹配的书，并读取当前画面上每种书的库存数量。库存、选中书、预览计数或颜色无法可靠识别时取消操作，不消耗书。

规划目标是满足当前技能剩余经验：在库存数量约束下，先使溢出经验最小，再使课程总时长最短，再使课程数量最少；候选状态只保留到“目标经验 + 最大单本经验”的有限边界，避免按库存数量展开成不可控的大状态。最终下发顺序按课程时长从长到短排列，减少先启动小课程造成的等待碎片。

技能预览的白色当前计数和绿色预计余量必须分开读取，绿色通过HSV掩码提取；预览分母必须是已知的下一等级经验，并满足 `0 <= white + green < denominator`。目标剩余经验必须落在 `0..18500`，否则按坏 OCR 处理。选中书带来的经验按一次预览修正计入：

```text
真实剩余 = 后续等级经验总和 - 白色当前值 - 绿色预计余量 + 当前选中书经验
```

满级预览是独立状态，不等同于 OCR 失败：除了明确的 `MAX`，国服还会保留数字计数并截断绿色增量，如选中3000经验书时显示 `4700+1100/5800`。只有末级分母5800、白色值在0到5799、绿色值为正且两者之和恰好5800时，才将数字预览识别为封顶。先尝试同色最小书并刷新预览；刷新后若未封顶，按新的真实剩余重新规划；若仍封顶，才使用该最小同色书完成当前动作。缺失选中书、库存未知、计数解析失败、其他分母封顶或数值越界都直接取消，不以 `MAX` 兜底。

2026-09-11修复了上述数字封顶导致取消开课、空栏每隔2至4小时重复失败的问题。实机先切换同色T1得到 `4700+150/5800`，计算剩余1100并选用T3（1200经验），随后另一空栏也正常补位。真实截图回归与状态流转测试覆盖该路径；一次成功开课不代表未来所有课程已完成验收。
